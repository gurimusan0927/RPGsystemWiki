# RPGsystem Wiki

`index.html`をダブルクリックしてブラウザで開いてください。インターネット接続や追加ソフトなしで、ページ移動・検索が使えます。HTMLとassetsフォルダを一緒に保管してください。

戦闘職10職、生産9分野、食材4分類に個別ページがあります。検索結果を選ぶと、折りたたみ項目も開いて表示します。

食材・装備能力・魔法はカード形式で、ページ内の検索と分類の絞り込みが使えます。食材はプール内の効果と特殊効果でも絞り込めます。魔法作成シミュレーションではMP・詠唱時間・基礎効果を、ダメージ計算シミュレーションでは独自補正後の数値と計算内訳を確認できます。魔法の基礎攻撃値はダメージ計算へ引き継げます。

計算対象と対象外の処理は、各シミュレーションページに記載しています。Minecraft側の防具や無敵時間などを含む実機の最終結果を保証するものではありません。

画像は同梱アドオンと提供されたバニラサンプルパックから使用しています。戦技アイテムには画像を使用していません。
