導入と基本操作

最初に使う道具と、操作の入口を確認します。

RPGsystem 1.26.6_9更新 2026.09.30

敵のレベル・階級・レア度、ランダム能力付き装備、プレイヤー育成、2職を組み合わせる戦闘職、自作魔法、9分野の生産、料理を追加するPvE中心のアドオンです。PvPがワールド全体で禁止になるわけではありません。主な攻撃能力・弱体処理がプレイヤー対モブを対象にしています。

項目同梱ファイルの設定
BP / RPの表示名RPGsystem [BP] / RPGsystem [RP]
内部バージョン両方とも1.26.6。ファイル名末尾の「_9」はmanifestの版番号には入っていない
最低エンジン版の宣言min_engine_version は両方とも [1,26,50]
Script API@minecraft/server 2.10.0、@minecraft/server-ui 2.2.0
構成BPが同梱RP 1.26.6を依存先に指定
プレイヤーレベル1～150
深度1～10、プレイヤーごとに保存
敵レベル最大100
戦闘職10職、同時に2職、合計200スキル
戦技89種類、装備枠は5枠
生産9分野、それぞれLv50まで。各分野10技能のうち段階ごとに片方を選択
装備能力76種類。通常装備のレア度7段階＋内部区分「特殊」
食材料理用の定義は81項目。水入り瓶など同じアイテムIDの条件違いを含む

最低版はアドオンに記載された宣言値です。起動できる製品版と実験設定の要否は、実際の利用環境で確認してください。

基本操作

操作内容
冒険手帳を使用RPGのメニューを開く
戦技ホイールを使用装備した戦技を選んで発動
戦技ホイールを持ちスニーク＋使用クイック対象を次の装備済み枠へ切り替える
ホイールを持ち、8tick以内にジャンプボタンを2回押すクイック対象の戦技を発動。20tick/秒換算で0.4秒以内
杖を使用選択中の魔法を詠唱して発動
杖を持ちスニーク＋使用杖に保存した魔法を順送り。空欄は飛ばす
杖を持って魔法作成台を殴る魔法の編集画面
調理台を使用材料を選んで調理
対象の道具でスニーク＋使用取得済み生産技能の発動・ON/OFF。候補が複数ある場合は選択画面
望遠鏡で敵を覗く敵の能力を調べる

「使用」はPCでは右クリックに相当する操作です。端末ごとのボタン表示そのものはこのWikiでは確定していません。クイック戦技はスニーク中・水中・飛行中・滑空中には入力を数えません。

冒険手帳と戦技ホイールは、参加・リスポーン時に未所持なら各1個支給されます。インベントリ内では移動できますが、捨てる・箱へ移す操作をロックし、死亡時も保持する設定です。2個目以降は整理されます。インベントリが満杯で支給できない場合は足元へ出す処理があります。
