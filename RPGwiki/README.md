# RPGsystem プレイヤーマニュアル

仕様基準：1.16.1（2026-09-19）

## 開き方

このフォルダの index.html をダブルクリックすると、マニュアルが開きます。ネット接続や追加ソフトは不要です。

## 内容

- 深度・敵スケーリング・階級・レア度
- レベル・ステータス・経験値
- 9分野・90生産スキルの検索
- 80食材の抽選プール検索、品質・追加抽選・反転
- 62装備能力の検索、武器別プール・7レア度の数値範囲
- 与ダメージ／被ダメージ計算機、会心・通常・条件付き期待値と途中式
- 全文検索（ひらがな・カタカナ対応）

## ファイル

- dist/index.html：ページの土台
- dist/style.css：パソコン・スマートフォン共通の見た目
- dist/home.js：トップページ
- dist/guides.js：各システムの解説
- dist/data.js：食材・スキル・装備能力のデータ
- dist/app.js：検索・絞り込み・ページ切り替え
- dist/calc.js：ダメージ計算（重要箇所に日本語コメント）
- tools/build-data.mjs：開発資料と同版の定義を照合してデータ更新
- tools/source-audit.json：参照資料の指紋と仕様の照合記録

## 計算機の範囲

近接・飛び道具の主対象1撃を計算します。「素のダメージ」はゲームから渡される値で、武器の表示攻撃力からバニラの処理まで再現するものではありません。特殊攻撃のチェックは、その一撃で発動した条件です。期待値は指定された発動条件のもとで会心等を平均します。

## データ更新

開発資料の更新時は仕様書の版を確認し、古い設計案と新しい実装を混在させないでください。データ再生成にはNode.jsと、元資料および同じ版のRPGsystem_BPが必要です。生成ツールは原資料を変更しません。仕様件数が変わった場合は生成時の検査と説明文も更新します。
